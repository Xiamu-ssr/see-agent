# see-agent v3.1 PRD — 多进程架构 + 沙箱隔离 + 屏幕租借 + launchd

> 版本：v3.1 | 作者：草莓🍓 + lanxuan | 日期：2026-03-10
> 目标：将 agent 改为独立子进程运行，实现内核级沙箱隔离、屏幕资源管理、后台服务化

---

## 1. 背景与动机

### 1.1 当前架构（v3.0）

```
单 Python 进程
├── FastAPI server
├── TeamManager
│   ├── AgentLoop "leader"  ← asyncio.Task
│   ├── AgentLoop "alice"   ← asyncio.Task
│   └── AgentLoop "bob"     ← asyncio.Task
├── TeamBus                 ← asyncio.Queue（内存）
├── TaskBoard               ← 内存 + tasks.json
├── MacEye                  ← 共享单例 + asyncio.Lock
└── ScreenLock              ← asyncio.Lock（step 级别互斥）
```

### 1.2 问题

| 问题 | 说明 |
|------|------|
| 无故障隔离 | 一个 agent 死循环/内存泄漏 → 整个进程崩溃 |
| 无安全隔离 | agent 可以访问任何文件/网络，tools_config 只是软限制 |
| 屏幕互相干扰 | asyncio.Lock 只防止同时操作，不防逻辑冲突（A 切浏览器，B 切钉钉） |
| 启动占终端 | `see-agent start` 必须占用一个 cmd 窗口 |

### 1.3 v3.1 目标

1. **多进程**：每个 agent 跑在独立子进程中
2. **沙箱隔离**：每个 agent 子进程跑在 macOS sandbox-exec 内核沙箱中
3. **屏幕租借**：agent 通过租约机制独占使用屏幕（10 分钟级）
4. **launchd 服务**：后台运行，不占终端

## 2. 新架构总览

```
主进程 (FastAPI server + launchd 管理)
│
├── AgentRouter (UDS server)
│   ├── Bus 消息转发
│   ├── TaskBoard 读写代理
│   ├── ScreenManager 屏幕租借
│   └── MacEye 截屏代理
│
├── Agent "leader" 子进程
│   ├── sandbox-exec 包裹
│   ├── UDS client → AgentRouter
│   └── AgentLoop（独立事件循环）
│
├── Agent "alice" 子进程
│   ├── sandbox-exec 包裹
│   ├── UDS client → AgentRouter
│   └── AgentLoop
│
└── Agent "bob" 子进程
    ├── sandbox-exec 包裹
    ├── UDS client → AgentRouter
    └── AgentLoop
```

**核心原则**：
- 主进程是 **Router + 资源管理者**，不跑 agent 逻辑
- agent 子进程是 **纯执行者**，所有共享资源通过 UDS 请求主进程
- sandbox-exec 在进程启动时包裹，运行时无法绕过（内核级）

## 3. 模块一：多进程 Agent

### 3.1 进程间通信（IPC）

**协议**：Unix Domain Socket (UDS)

**为什么选 UDS**：
- 零网络开销（内核 buffer 直传）
- 天然安全（文件权限控制）
- Python 标准库 asyncio 原生支持
- 未来可平滑迁移到 TCP（分布式场景）

**Socket 路径**：`~/.see-agent/run/{team_id}.sock`

**消息格式**：JSON-RPC 风格

```json
// 请求
{"id": 1, "method": "bus.send", "params": {"sender": "alice", "recipient": "leader", "content": "API 写好了"}}

// 响应
{"id": 1, "result": {"status": "ok"}}
```

### 3.2 AgentRouter（主进程）

```python
class AgentRouter:
    """主进程中的 RPC server，处理所有 agent 子进程的请求。"""

    def __init__(self, team_id: str):
        self._bus = TeamBus(TEAMS_DIR / team_id)
        self._board = TaskBoard(TEAMS_DIR / team_id)
        self._eye = MacEye()
        self._screen = ScreenManager()
        self._sock_path = RUN_DIR / f"{team_id}.sock"

    async def start(self):
        """启动 UDS server，监听 agent 请求。"""
        server = await asyncio.start_unix_server(
            self._handle_connection, path=str(self._sock_path)
        )
        ...

    async def _handle_connection(self, reader, writer):
        """处理单个 agent 连接。"""
        while True:
            data = await reader.readline()
            if not data:
                break
            request = json.loads(data)
            result = await self._dispatch(request)
            writer.write(json.dumps(result).encode() + b"\n")
            await writer.drain()

    async def _dispatch(self, request: dict) -> dict:
        """路由请求到对应的处理方法。"""
        method = request["method"]
        params = request.get("params", {})

        handlers = {
            # Bus 通信
            "bus.send": self._bus_send,
            "bus.drain": self._bus_drain,
            # TaskBoard
            "board.list": self._board_list,
            "board.create": self._board_create,
            "board.claim": self._board_claim,
            "board.complete": self._board_complete,
            "board.update": self._board_update,
            "board.assign": self._board_assign,
            # 屏幕
            "screen.acquire": self._screen_acquire,
            "screen.release": self._screen_release,
            "screen.capture": self._screen_capture,
            "screen.click": self._screen_click,
            "screen.type_text": self._screen_type,
            "screen.scroll": self._screen_scroll,
            "screen.drag": self._screen_drag,
            "screen.hotkey": self._screen_hotkey,
        }

        handler = handlers.get(method)
        if handler is None:
            return {"id": request["id"], "error": f"Unknown method: {method}"}
        result = await handler(**params)
        return {"id": request["id"], "result": result}
```

### 3.3 AgentWorker（子进程入口）

```python
# see_agent/agent/worker.py — agent 子进程的入口
"""Agent worker process — runs a single AgentLoop with UDS-based IPC."""

import asyncio
import json
import sys
from pathlib import Path


class UDSClient:
    """连接主进程 AgentRouter 的客户端。"""

    def __init__(self, sock_path: Path):
        self._sock_path = sock_path
        self._reader = None
        self._writer = None
        self._counter = 0

    async def connect(self):
        self._reader, self._writer = await asyncio.open_unix_connection(
            str(self._sock_path)
        )

    async def call(self, method: str, **params) -> dict:
        self._counter += 1
        request = {"id": self._counter, "method": method, "params": params}
        self._writer.write(json.dumps(request).encode() + b"\n")
        await self._writer.drain()
        data = await self._reader.readline()
        response = json.loads(data)
        if "error" in response:
            raise RuntimeError(response["error"])
        return response.get("result", {})


class RemoteBus:
    """TeamBus 的远程代理——通过 UDS 调用主进程。"""

    def __init__(self, client: UDSClient, agent_id: str):
        self._client = client
        self._agent_id = agent_id

    def send(self, msg):
        asyncio.get_event_loop().run_until_complete(
            self._client.call("bus.send",
                sender=msg.sender, recipient=msg.recipient, content=msg.content)
        )

    def drain(self, agent_id: str):
        result = asyncio.get_event_loop().run_until_complete(
            self._client.call("bus.drain", agent_id=agent_id)
        )
        return result.get("messages", [])


class RemoteScreenTools:
    """屏幕 tool 的远程代理——通过 UDS 请求主进程操作。"""

    def __init__(self, client: UDSClient, agent_id: str):
        self._client = client
        self._agent_id = agent_id

    async def capture(self) -> dict:
        return await self._client.call("screen.capture", agent_id=self._agent_id)

    async def click(self, x: int, y: int) -> dict:
        return await self._client.call("screen.click",
            agent_id=self._agent_id, x=x, y=y)

    async def type_text(self, text: str) -> dict:
        return await self._client.call("screen.type_text",
            agent_id=self._agent_id, text=text)
    # ... scroll, drag, hotkey 同理
```

### 3.4 TeamManager 改造

```python
class TeamManager:
    """v3.1: 主进程管理 agent 子进程。"""

    async def run(self, task: str) -> TeamRunResult:
        # 1. 启动 AgentRouter（UDS server）
        router = AgentRouter(self._team_def.id)
        await router.start()

        # 2. 启动 agent 子进程
        processes: dict[str, subprocess.Popen] = {}
        for agent_id in self._team_def.members:
            proc = self._spawn_agent(agent_id, task, router.sock_path)
            processes[agent_id] = proc

        # 3. 等待所有子进程完成
        results = {}
        for agent_id, proc in processes.items():
            proc.wait()
            results[agent_id] = self._collect_result(agent_id, proc)

        # 4. 清理
        await router.stop()
        return TeamRunResult(...)

    def _spawn_agent(self, agent_id, task, sock_path) -> subprocess.Popen:
        """启动 agent 子进程（可选 sandbox-exec 包裹）。"""
        agent_def = AgentDefinition.load(agent_id)
        config_path = self._write_agent_config(agent_id)

        cmd = [
            sys.executable, "-m", "see_agent.agent.worker",
            str(config_path), str(sock_path), task,
        ]

        # 如果启用沙箱，用 sandbox-exec 包裹
        sandbox_cfg = agent_def.sandbox or {}
        if sandbox_cfg.get("enabled", False):
            profile_path = self._generate_sandbox_profile(agent_id)
            cmd = ["sandbox-exec", "-f", str(profile_path)] + cmd

        return subprocess.Popen(
            cmd,
            stdout=open(self._agent_log_path(agent_id), "a"),
            stderr=subprocess.STDOUT,
        )
```

## 4. 模块二：沙箱隔离（sandbox-exec）

### 4.1 设计原则

**默认够用，例外才调整。** 用户不需要手动添加权限，开箱即用。

### 4.2 Profile 分层

```
see-agent sandbox profile =
    Safehouse 基础层（复用）
  + see-agent 固定层（我们写的）
  + agent 动态层（自动生成）
```

#### 层 1：Safehouse 基础层（复用）

来自开源项目 [agent-safehouse](https://github.com/eugene1g/agent-safehouse)，使用 macOS 内核级 `sandbox-exec` 隔离 agent 进程。

**全部 54 个 profile 文件已复制到 `see_agent/sandbox/profiles/` 目录**，保留原始目录结构：

```
see_agent/sandbox/profiles/
├── 00-base.sb                              ← (deny default) + HOME_DIR 宏
├── 10-system-runtime.sb                    ← /usr, /bin, /System 等系统运行时
├── 20-network.sb                           ← 网络连接
├── 30-toolchains/
│   ├── python.sb                           ← Python 解释器 + venv + pip
│   ├── node.sb                             ← Node.js + npm + npx
│   ├── bun.sb / deno.sb / go.sb / ...     ← 其他工具链
│   └── runtime-managers.sb                 ← nvm, pyenv, asdf 等
├── 40-shared/
│   └── agent-common.sb                     ← 通用 agent 目录（~/.skills 等）
├── 50-integrations-core/
│   ├── git.sb                              ← git 操作
│   ├── scm-clis.sb                         ← gh, gitlab-cli 等
│   ├── launch-services.sb                  ← macOS Launch Services
│   └── container-runtime-default-deny.sb   ← 默认拒绝容器
├── 55-integrations-optional/

│   ├── clipboard.sb                        ← 剪贴板访问
│   ├── macos-gui.sb                        ← GUI 操作权限

│   └── ... 共 17 个可选 profile
├── 60-agents/

└── see-agent-base.sb                       ← ★ 我们自己写的 see-agent 通用权限
```

**profile 语法**（macOS sandbox-exec 的 TinySCHEME）：
- `(deny default)` — 默认拒绝一切
- `(allow file-read* (subpath "/usr"))` — 允许读 /usr 下所有文件
- `(allow file-read* file-write* (subpath "/tmp"))` — 允许读写 /tmp
- `(define HOME_DIR "/Users/xxx")` — 定义 HOME 路径变量
- `(home-subpath "/Documents")` — 匹配 HOME/Documents 子路径

**使用方式**：`sandbox-exec -f <combined-profile.sb> python -m see_agent.agent.worker ...`

**profile 组合策略**：

see-agent 的 sandbox profile 由以下层拼接而成：

| 层 | 文件 | 何时包含 |
|----|------|---------|
| 基础 | `00-base.sb` | 始终 |
| 系统运行时 | `10-system-runtime.sb` | 始终 |
| 网络 | `20-network.sb` | `sandbox.network == true` 时 |
| Python 工具链 | `30-toolchains/python.sb` | 始终（agent 是 Python 进程） |
| Node 工具链 | `30-toolchains/node.sb` | agent 有 MCP server 用 npx 时 |
| 运行时管理器 | `30-toolchains/runtime-managers.sb` | 始终（pyenv/nvm 等） |
| agent 通用 | `40-shared/agent-common.sb` | 始终 |
| git | `50-integrations-core/git.sb` | 始终 |
| scm | `50-integrations-core/scm-clis.sb` | 始终 |
| GUI 操作 | `55-integrations-optional/macos-gui.sb` | `sandbox.screen_access == true` 时 |
| 剪贴板 | `55-integrations-optional/clipboard.sb` | `sandbox.screen_access == true` 时 |
| shell-init | `55-integrations-optional/shell-init.sb` | 始终 |
| see-agent 通用 | `see-agent-base.sb` | 始终 |

CC 实现 `sandbox/manager.py` 时，根据上表的条件拼接 `.sb` 文件内容，加上动态生成的 agent 目录权限，写入一个临时的 `<team_id>-<agent_id>.sb` 文件，然后用 `sandbox-exec -f` 启动子进程。

#### 层 3：agent 动态层（自动生成）

根据 agent 所在位置动态生成，**加入 team 时自动授权**：

```python
def _generate_sandbox_profile(self, agent_id: str) -> Path:
    """为 agent 生成 sandbox profile，自动包含其目录权限。"""

    # 确定 agent 目录
    team_id = self._team_def.id
    agent_dir = TEAMS_DIR / team_id / "agents" / agent_id
    shared_dir = TEAMS_DIR / team_id / "shared"

    # 读取用户自定义权限（如果有）
    agent_def = AgentDefinition.load(agent_id)
    sandbox_cfg = agent_def.sandbox or {}
    extra_read = sandbox_cfg.get("extra_read", [])
    extra_write = sandbox_cfg.get("extra_write", [])

    dynamic_rules = f"""
;; 动态生成 — agent: {agent_id}, team: {team_id}

;; agent 自身目录（读写）
(allow file-read* file-write*
    (subpath "{agent_dir}")
)

;; team 共享工作区（读写）
(allow file-read* file-write*
    (subpath "{shared_dir}")
)
"""

    # 用户自定义的额外权限
    for path in extra_read:
        expanded = str(Path(path).expanduser())
        dynamic_rules += f'(allow file-read* (subpath "{expanded}"))\n'
    for path in extra_write:
        expanded = str(Path(path).expanduser())
        dynamic_rules += f'(allow file-read* file-write* (subpath "{expanded}"))\n'

    # 组合所有层
    profile_content = self._combine_profiles(dynamic_rules)
    profile_path = RUN_DIR / f"{team_id}-{agent_id}.sb"
    profile_path.write_text(profile_content)
    return profile_path

def _combine_profiles(self, dynamic_rules: str) -> str:
    """将 Safehouse 基础层 + see-agent 固定层 + 动态层组合成完整 profile。"""
    parts = []
    profiles_dir = Path(__file__).parent.parent / "sandbox" / "profiles"

    # Safehouse 基础层
    for name in ["00-base.sb", "10-system-runtime.sb", "20-network.sb",
                  "30-toolchains/python.sb", "see-agent-base.sb"]:
        path = profiles_dir / name
        if path.exists():
            parts.append(path.read_text())

    # 动态层
    parts.append(dynamic_rules)

    return "\n\n".join(parts)
```

### 4.5 权限拒绝收集与一键允许

agent 子进程的 sandbox 拒绝记录通过 macOS unified log 收集：

```python
class SandboxViolationCollector:
    """收集 agent 子进程的 sandbox 拒绝记录。"""

    async def collect(self, agent_pid: int, since_minutes: int = 60) -> list[dict]:
        """从 macOS unified log 中提取指定 PID 的 sandbox violation。"""
        result = await asyncio.create_subprocess_exec(
            "log", "show",
            "--predicate", f'processID == {agent_pid} AND category == "Sandbox"',
            "--last", f"{since_minutes}m",
            "--style", "json",
            stdout=asyncio.subprocess.PIPE,
        )
        stdout, _ = await result.communicate()
        # 解析日志，提取被拒绝的路径/操作
        violations = self._parse_violations(stdout.decode())
        return violations

    def _parse_violations(self, log_json: str) -> list[dict]:
        """解析 unified log JSON，提取 deny 记录。"""
        entries = json.loads(log_json) if log_json.strip() else []
        violations = []
        for entry in entries:
            msg = entry.get("eventMessage", "")
            if "deny" in msg.lower():
                # 提取被拒绝的路径
                path = self._extract_path(msg)
                violations.append({
                    "timestamp": entry.get("timestamp", ""),
                    "operation": self._extract_operation(msg),
                    "path": path,
                    "raw": msg,
                })
        return violations
```

**注意**：沙箱权限变更不会立刻对正在运行的 agent 生效（因为 sandbox-exec 是进程启动时生效的）。需要重启 agent 子进程。前端提示"权限已更新，将在 agent 下次启动时生效"。

## 5. 模块三：屏幕租借系统（ScreenManager）

### 5.1 设计原则

屏幕是**物理独占资源**。两个 agent 混着用 Mac 屏幕（step 级别交替）一定会互相干扰——A 切到浏览器，B 切到钉钉，A 回来发现屏幕变了。

所以屏幕租借是 **10 分钟级别的租约**，不是 step 级别的锁。

### 5.2 核心概念

| 概念 | 说明 |
|------|------|
| **租约 (Lease)** | agent 获得屏幕后独占使用的时间段，默认 10 分钟 |
| **续约** | agent 每次使用屏幕 tool 自动续约（重置空闲计时器） |
| **提前归还** | agent 可以主动释放（做完屏幕操作后） |
| **空闲释放** | 5 分钟未使用屏幕 tool → 自动释放 |
| **到期释放** | 超过最大租约时间 → 强制释放 |
| **排队** | 租约被占时，新请求进入等待队列 |

### 5.3 ScreenManager 实现

```python
@dataclass
class ScreenLease:
    """一个屏幕租约。"""
    holder: str              # "team_id:agent_id"
    started_at: float
    last_used_at: float
    max_duration: int = 600  # 默认 10 分钟
    idle_timeout: int = 300  # 5 分钟不用自动释放

class ScreenManager:
    """全局屏幕租借管理器（主进程中的单例）。"""

    def __init__(self):
        self._lease: ScreenLease | None = None
        self._queue: list[tuple[str, asyncio.Event]] = []  # (holder_id, event)
        self._eye = MacEye()
        self._check_task: asyncio.Task | None = None

    async def start(self):
        """启动定期检查过期租约的任务。"""
        self._check_task = asyncio.create_task(self._expiry_checker())

    async def stop(self):
        if self._check_task:
            self._check_task.cancel()

    def is_holder(self, holder_id: str) -> bool:
        return self._lease is not None and self._lease.holder == holder_id

    async def acquire(self, holder_id: str, duration: int = 600) -> bool:
        """申请屏幕租约。
        - 空闲 → 立即获得，返回 True
        - 被占 → 加入队列，返回 False（agent 应去做其他工作）
        """
        if self._lease is None:
            self._lease = ScreenLease(
                holder=holder_id,
                started_at=time.time(),
                last_used_at=time.time(),
                max_duration=duration,
            )
            logger.info("Screen lease granted to %s (%ds)", holder_id, duration)
            return True

        if self._lease.holder == holder_id:
            return True  # 已持有

        # 排队
        event = asyncio.Event()
        self._queue.append((holder_id, event))
        logger.info("Screen lease queued for %s (pos %d)", holder_id, len(self._queue))
        return False

    async def release(self, holder_id: str):
        """主动释放租约。"""
        if self._lease and self._lease.holder == holder_id:
            logger.info("Screen lease released by %s", holder_id)
            self._lease = None
            await self._grant_next()

    def touch(self, holder_id: str):
        """agent 使用了屏幕，重置空闲计时器。"""
        if self._lease and self._lease.holder == holder_id:
            self._lease.last_used_at = time.time()

    async def _grant_next(self):
        """将租约授予队列中下一个等待者。"""
        while self._queue:
            holder_id, event = self._queue.pop(0)
            self._lease = ScreenLease(
                holder=holder_id,
                started_at=time.time(),
                last_used_at=time.time(),
            )
            event.set()  # 通知等待者
            logger.info("Screen lease granted to %s (from queue)", holder_id)
            return

    async def _expiry_checker(self):
        """每 10 秒检查租约是否过期或空闲。"""
        while True:
            await asyncio.sleep(10)
            if self._lease is None:
                continue
            now = time.time()
            # 租约到期
            if now - self._lease.started_at > self._lease.max_duration:
                logger.info("Screen lease expired for %s (max duration)",
                    self._lease.holder)
                holder = self._lease.holder
                self._lease = None
                await self._grant_next()
            # 空闲超时
            elif now - self._lease.last_used_at > self._lease.idle_timeout:
                logger.info("Screen lease expired for %s (idle timeout)",
                    self._lease.holder)
                self._lease = None
                await self._grant_next()
```

3. **TeamManager.stop()** — 逐个终止 agent 子进程

```python
async def stop(self):
    """停止所有 agent 子进程。"""
    for agent_id, proc in self._processes.items():
        proc.terminate()
        try:
            proc.wait(timeout=5)
        except subprocess.TimeoutExpired:
            proc.kill()
    self._processes.clear()
    if self._router:
        await self._router.stop()
```

## 11. 设计约束与注意事项

1. **向后兼容**：如果 sandbox.enabled 为 false（或不存在），agent 以普通子进程运行（不加 sandbox-exec），行为和 v3.0 的 asyncio.Task 等效
2. **macOS only**：sandbox-exec 是 macOS 专属。Linux 上可以后续用 seccomp/AppArmor 替代，但 v3.1 只做 macOS
3. **UDS 性能**：JSON-RPC over UDS 的延迟约 0.1~0.5ms，对 agent loop 的影响可忽略（LLM API 调用是秒级的）
4. **子进程资源**：每个 Python 子进程约 30~50MB 内存。12 人 team ≈ 多 360~600MB，对 16GB Mac 可接受
5. **屏幕租约不跨 team**：ScreenManager 是全局的，不同 team 的 agent 共享同一个租约队列
6. **sandbox profile 版本**：Safehouse 的 profile 可能随 macOS 版本更新，需要定期同步。建议把 Safehouse 作为 git submodule 或定期手动同步
7. **leader 优先级**：team 启动时 leader 自动获得屏幕租约（如果需要屏幕的话）。worker 需要排队等 leader 释放
8. **agent 无感**：agent 的 prompt 和逻辑不需要知道"多进程"或"屏幕租借"，这些都在基础设施层透明处理
