# v4.1 前端 UI 精修 + 移动端适配

## 目标
精修所有页面的间距、排版、视觉一致性，并添加移动端自适应。

## 工作目录
`/Users/lanxuan/Code/computer-use-and-memory-agent/web`

## 设计原则
1. **呼吸感**：元素间留够间距，不要挤在一起，但也不要太空
2. **层次分明**：标题 > 正文 > 辅助信息，用字号和颜色区分
3. **对齐统一**：同一页面的 padding/margin 保持一致（用 4 的倍数：4/8/12/16/20/24px）
4. **移动优先**：断点 `lg:1024px`，小屏隐藏 sidebar 用汉堡菜单
5. **参考风格**：类似 Linear / Vercel Dashboard 的简洁暗色风格

## 断点规则
- `< 768px`（手机）：sidebar 完全隐藏，底部 tab bar；agent 列表全屏；detail 全屏
- `768px ~ 1024px`（平板）：sidebar 收起为图标栏 + overlay；agent 列表 + detail 分栏
- `> 1024px`（桌面）：sidebar 图标栏固定；agent 列表 + detail 分栏

## 一、Sidebar 精修

当前问题：
- 每个导航项 h-[52px] 太高，图标和文字间距大
- Logo 区域 "S" 太简单

改动：

- 平板/小桌面（768~1024px）：sidebar 默认隐藏，左上角汉堡菜单触发 overlay
- 大桌面（> 1024px）：保持现有图标栏

## 六、全局样式精修

1. **所有 Card/Panel**：统一 border-radius 为 var(--radius-lg)（12px），padding 16px
2. **所有标题**：页面标题 text-xl font-semibold，section 标题 text-base font-medium
3. **所有按钮**：统一用 shadcn Button，主操作 default，次要操作 outline/ghost
4. **所有状态**：
   - idle → 灰色圆点 + "Idle" 文字
   - busy → 绿色圆点 + "Running" 文字
   - error → 红色圆点 + "Error" 文字
5. **过渡动画**：hover 用 transition-colors duration-150，页面切换用 fade

## 实施约束

1. **不改后端 Python 代码**
2. **不改 API 层**（`src/api/`）
3. **不改路由结构**（`router.tsx`）
4. **不改类型定义**（`src/types/`）
5. **保留所有现有功能**——只改样式和布局
6. **每改完一个文件跑 `npx tsc --noEmit`**
7. **最后跑 `npx vite build` 确认构建通过**
8. **一次性提交**：`v4.1: UI polish + mobile responsive — all pages`
9. **不改 CodeEditor.tsx**（Monaco 组件保持不变）
10. **不改 PixelOffice 相关组件**（保持原样）
11. **CSS 变量全部用 globals.css 里定义的**，不要新增
