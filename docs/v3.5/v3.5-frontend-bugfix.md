## 改动一：Agent ID 自动生成

### 现状

`web/src/pages/AgentsPage.tsx` 的 Create Agent 弹窗有 3 个输入框（Agent ID、Display name、Role），要求用户手动填 ID。后端 `CreateAgentRequest` 的 `id` 字段为必填。

### 要求

用户只需填 Name 和 Role，ID 由后端自动生成。

### 改动

#### 后端 `see_agent/server/routes/agents.py`

```python
# CreateAgentRequest: id 改为可选
class CreateAgentRequest(BaseModel):
    id: str | None = None          # ← 原来是 id: str
    name: str
    role: str = "general assistant"
    soul: str | None = None
    config_overrides: dict[str, Any] | None = None
```

```python
# create_agent 函数开头：自动生成 ID
async def create_agent(body: CreateAgentRequest) -> AgentCreateResponse:
    import secrets, string
    agent_id = body.id or ''.join(
        secrets.choice(string.ascii_lowercase + string.digits) for _ in range(6)
    )
    # 后续所有 body.id 替换为 agent_id
    ...
```

#### 前端 `web/src/pages/AgentsPage.tsx`

1. 删除 `form` state 中的 `id` 字段，改为 `{ name: '', role: 'general assistant' }`
2. 删除 Create Agent 弹窗中的 "Agent ID" `<input>`
3. `handleCreate` 中删除 `if (!form.id || ...)` 的 id 校验
4. CreateAgentRequest 类型中 `id` 变为 optional

## 改动二：Agent 页面改为左列表 + 右详情

这是**最大的改动**。对照 `02-agents-detail.png` 和 `03-agents-chat.png`。

### 现状

- `AgentsPage.tsx`：全宽表格，点击行跳转到 `/agents/:id`
- `AgentDetailPage.tsx`：独立的详情页面，包含 Overview/Files/Tools/Skills/Safehouse/Chat 共 6 个 tab

### 要求

合并为一个页面，左侧 agent 列表 + 右侧内容区。**删除 `AgentDetailPage.tsx`**。

### 路由改动 `web/src/router.tsx`

```tsx
// 删除 AgentDetailPage 的 import
// 改为：
{ path: '/agents', element: <AgentsPage /> },
{ path: '/agents/:id', element: <AgentsPage /> },        // Details 模式
{ path: '/agents/:id/chat', element: <AgentsPage /> },   // Chat 模式
// 删除原来的 { path: '/agents/:id', element: <AgentDetailPage /> }
```

### AgentsPage.tsx 完整重写

页面结构（参照 mockup 02）：

```
┌──────────────────────────────────────────────────────────┐
│                                                          │
│  ┌──────────┐  ┌──────────────────────────────────────┐ │
│  │ 左栏      │  │ 右栏                                 │ │
│  │ 280px     │  │                                     │ │
│  │           │  │ Agent 名称 + 角色 + 状态 badge       │ │
│  │ "Agents"  │  │                                     │ │
│  │ "4 agents"│  │ [Details] [Chat]  ← 同级切换         │ │
│  │           │  │                                     │ │
│  │ Agent 卡片 │  │ Details 时:                         │ │
│  │ Agent 卡片 │  │   Tab: Overview|Files|Tools|...     │ │
│  │ Agent 卡片 │  │   Tab 内容区                        │ │
│  │ Agent 卡片 │  │                                     │ │
│  │           │  │ Chat 时:                             │ │
│  │ +New Agent│  │   消息历史                            │ │
│  │           │  │   输入框 + ☐Steer + Send             │ │
│  └──────────┘  └──────────────────────────────────────┘ │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

关键交互：
- URL `/agents` → 左侧列表 + 右侧显示 "Select an agent"
- URL `/agents/:id` → 左侧列表（:id 高亮）+ 右侧 Details 模式
- URL `/agents/:id/chat` → 左侧列表（:id 高亮）+ 右侧 Chat 模式
- 点击左侧 agent → `navigate('/agents/${id}')`
- 点击 [Details] → `navigate('/agents/${id}')`
- 点击 [Chat] → `navigate('/agents/${id}/chat')`
- **[Details] 和 [Chat] 是同级切换按钮**（参考 mockup 中的 pill toggle），不是 tab 之一

Details 模式下的 5 个 tab（Overview / Files / Tools / Skills / Safehouse）：
- 用 `useState` 管理当前选中 tab，不需要路由
- Overview：2x3 信息卡片网格（ID、Name、Role、Status、Team、Model）
- Files：workspace 文件列表 + [Edit]/[View] 按钮（调 `GET /api/agents/{id}/workspace`）
- Tools：工具列表 + 开关（调 `GET /api/agents/{id}/tools`）
- Skills：agent 已安装的 skill
- Safehouse：sandbox 配置展示

Chat 模式（参考 mockup 03）：
- 消息历史区域（调 `GET /api/agents/{id}/chat` 获取历史）
- 消息气泡：用户消息右对齐，agent 消息左对齐
- 底部输入栏：文本输入框 + `☐ Steer` checkbox + coral `Send` 按钮
- 发送：`POST /api/agents/{id}/message`，body `{ content, priority }` 
  - Steer 勾选时 `priority: "steer"`，否则 `priority: "normal"`

删除 `web/src/pages/AgentDetailPage.tsx`，其逻辑全部移入 AgentsPage.tsx 或拆为子组件：

## 改动四：Team 消息发送修复

### 现状

`web/src/pages/TeamDetailPage.tsx` 中 `recipient` state 默认为空字符串。只有在 `loadData` 中 `t.leader` 存在时才设置。如果 team 没有 leader（或 leader 为空），recipient 一直为空，`handleSend` 中 `if (!recipient) return` 导致消息永远发不出去。

### 要求

`recipient` 默认选中第一个 team member。

### 改动 `web/src/pages/TeamDetailPage.tsx`

找到 `loadData` 函数中设置 recipient 的位置，改为：

```tsx
// 原来：
if (!recipient && t.leader) setRecipient(t.leader)

// 改为：
if (!recipient && t.members.length > 0) {
  setRecipient(t.leader || t.members[0])
}
```

另外：当 team 没有成员时，禁用发送按钮：
```tsx
<button
  onClick={handleSend}
  disabled={!members || members.length === 0}
  ...
>
  Send
</button>
```

## 改动五：创建 Team 改为下拉多选

### 现状

`web/src/pages/TeamsPage.tsx` Create Team 弹窗中 members 是手动输入 agent ID 的文本框（`<input placeholder="Add member ID">`），用户需要记住并手打 agent ID。

### 要求

改为从 agent 列表中多选（checkbox），Leader 从已选成员中下拉选择。

### 改动 `web/src/pages/TeamsPage.tsx`

1. 弹窗打开时调 `GET /api/agents` 加载 agent 列表
2. 成员选择改为 checkbox 列表：

```tsx
const [availableAgents, setAvailableAgents] = useState<AgentSummary[]>([])
const [selectedMembers, setSelectedMembers] = useState<string[]>([])
const [leader, setLeader] = useState<string>('')

// 弹窗打开时加载
useEffect(() => {
  if (showCreate) {
    listAgents().then(agents => setAvailableAgents(agents || []))
  }
}, [showCreate])

// 切换成员选中
const toggleMember = (id: string) => {
  setSelectedMembers(prev =>
    prev.includes(id) ? prev.filter(x => x !== id) : [...prev, id]
  )
}
```

3. 弹窗 UI：

```tsx
{/* Members 多选 */}
<div>
  <label className="text-xs font-medium" style={{ color: 'var(--muted)' }}>
    Members
  </label>
  <div className="mt-1 max-h-40 overflow-y-auto rounded border p-2"
       style={{ borderColor: 'var(--border)', background: 'var(--bg)' }}>
    {availableAgents.map(a => (
      <label key={a.id} className="flex items-center gap-2 py-1 text-sm cursor-pointer"
             style={{ color: 'var(--text)' }}>
        <input
          type="checkbox"
          checked={selectedMembers.includes(a.id)}
          onChange={() => toggleMember(a.id)}
          style={{ accentColor: 'var(--accent)' }}
        />
        {a.name} ({a.id})
      </label>
    ))}
    {availableAgents.length === 0 && (
      <p className="text-xs py-2" style={{ color: 'var(--muted)' }}>
        No agents available. Create agents first.
      </p>
    )}
  </div>
</div>

{/* Leader 下拉（从已选成员中选） */}
{selectedMembers.length > 0 && (
  <div>
    <label className="text-xs font-medium" style={{ color: 'var(--muted)' }}>
      Leader
    </label>
    <select
      value={leader}
      onChange={e => setLeader(e.target.value)}
      className="mt-1 w-full rounded border px-3 py-2 text-sm"
      style={{ background: 'var(--bg)', borderColor: 'var(--border)', color: 'var(--text)' }}
    >
      <option value="">Select leader...</option>
      {selectedMembers.map(id => (
        <option key={id} value={id}>{id}</option>
      ))}
    </select>
  </div>
)}
```

4. 删除旧的 `memberInput` state 和 `<input placeholder="Add member ID">` 相关代码
5. `handleCreate` 中 `form.members` 改为 `selectedMembers`，新增 `leader` 字段
