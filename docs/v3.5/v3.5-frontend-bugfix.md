## Bug 1: Create Agent 不应让用户填 ID

**文件**: `web/src/pages/AgentsPage.tsx`, `see_agent/server/routes/agents.py`, `see_agent/agent/definition.py`

**现状**: Create Agent 弹窗有 3 个输入框：Agent ID、Display name、Role。用户需要手动填 ID。

**修改**:
1. 前端：删除 "Agent ID" 输入框，只保留 Name 和 Role
2. 后端 `POST /api/agents`：如果 body 中没有 id，自动生成 6 位随机字符 ID（小写字母+数字）
3. `AgentDefinition.create()`：id 参数改为可选，默认自动生成

```python
# definition.py
import secrets
import string

def _generate_id(length: int = 6) -> str:
    chars = string.ascii_lowercase + string.digits
    return ''.join(secrets.choice(chars) for _ in range(length))
```

## Bug 2: Agent 页面布局不对

**文件**: `web/src/pages/AgentsPage.tsx`, `web/src/pages/AgentDetailPage.tsx`

**现状**: AgentsPage 是一个 agent 列表表格，点击跳转到 `/agents/:id` 详情页（全新页面）。

**要求**: 改成 **左列表 + 右详情** 同页布局（参考 OpenClaw 截图）。

### 具体实现：

**AgentsPage.tsx** 改为包含左右两栏的页面：

```
/agents          → 左侧列表 + 右侧空状态（"选择一个 agent"）
/agents/:id      → 左侧列表 + 右侧详情
/agents/:id/chat → 左侧列表 + 右侧聊天
```

左侧（固定宽度 280px）：
```
Agents
3 configured  [Refresh]

┌──────────────┐
│ 🤖 alice     │ ← 点击选中，右侧显示详情
│    ● running │
├──────────────┤
│ 🤖 bob       │
│    ○ idle    │
└──────────────┘

[+ New Agent]
```

右侧：顶部有两个切换按钮 **[Details]** 和 **[Chat]**
- 选中 Details 时：显示 agent 详情（Overview / Files / Tools / Skills / Safehouse 5 个 tab）
- 选中 Chat 时：显示聊天界面（消息历史 + 输入框 + steer checkbox）

**Details 和 Chat 是同级切换**，Chat 不是 tab 之一！

### 路由：
```tsx
{ path: '/agents', element: <AgentsPage /> },
{ path: '/agents/:id', element: <AgentsPage /> },
{ path: '/agents/:id/chat', element: <AgentsPage /> },
```
全部渲染同一个 AgentsPage，通过 URL params 决定左侧选中哪个 agent、右侧显示 Details 还是 Chat。

### 删除独立的 AgentDetailPage.tsx
所有详情内容移入 AgentsPage.tsx（或拆为子组件放 components/agents/ 下）。

## Bug 5: 创建 Team 应该下拉多选

**文件**: `web/src/pages/TeamsPage.tsx`（或创建 Team 的弹窗组件）

**现状**: 创建 team 时 members 字段是手动输入 agent ID 的文本框。

**修改**: 改为多选下拉（checkbox list），从 `GET /api/agents` 获取所有 agent 列表。

```tsx
// 1. 加载 agent 列表
const [availableAgents, setAvailableAgents] = useState<AgentSummary[]>([])
useEffect(() => { listAgents().then(setAvailableAgents) }, [])

// 2. 多选 UI
{availableAgents.map(a => (
  <label key={a.id} className="flex items-center gap-2">
    <input
      type="checkbox"
      checked={selectedMembers.includes(a.id)}
      onChange={() => toggleMember(a.id)}
    />
    {a.name} ({a.id})
  </label>
))}

// 3. Leader 下拉
<select value={leader} onChange={e => setLeader(e.target.value)}>
  {selectedMembers.map(id => (
    <option key={id} value={id}>{id}</option>
  ))}
</select>
```
